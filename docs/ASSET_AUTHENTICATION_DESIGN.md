# 资产真实性验证方案设计

## 1. 概述

为了证明用户提交的资产的真实性，MantleLuxury 平台采用**多层次、可验证、链上存证**的认证体系。

## 2. 验证维度

### 2.1 基础信息验证
- **序列号验证**：与品牌官方数据库或授权经销商核对
- **购买凭证**：发票、收据、转账记录等
- **历史记录**：资产流转历史、维修记录等

### 2.2 专业鉴定
- **第三方鉴定机构**：至少 2 家权威机构独立鉴定
- **鉴定报告**：包含详细的技术分析、真伪结论、鉴定师签名
- **AI 辅助识别**：结合图像识别技术进行初步筛查

### 2.3 估值验证
- **多家估值机构**：至少 2 家独立估值机构给出估值
- **估值报告**：包含市场分析、同类资产对比、估值依据
- **定期复检**：高价值资产每年复检一次

### 2.4 托管与保险
- **托管证明**：资产进入合格托管机构，提供托管凭证
- **保险证明**：购买全险，保额不低于估值
- **链上存证**：托管和保险信息哈希上链

## 3. 技术实现

### 3.1 数据库设计

#### asset_authentications 表
存储真伪认证信息：
- `id`: 主键
- `asset_id`: 关联资产 ID
- `authentication_status`: 认证状态（pending, verified, rejected）
- `authenticator_name`: 鉴定机构名称
- `authenticator_type`: 机构类型（official_brand, third_party, ai_system）
- `verification_date`: 认证日期
- `report_url`: 认证报告 URL（IPFS 或 S3）
- `report_hash`: 报告哈希（链上存证）
- `verifier_signature`: 鉴定师签名/证书
- `notes`: 备注信息

#### asset_valuations 表（已存在，扩展）
- 增加 `valuation_type`: 估值类型（initial, revaluation）
- 增加 `valuation_method`: 估值方法（market_comparison, cost_approach, income_approach）

### 3.2 链上存证

所有关键证明文件通过以下方式存证：
1. **IPFS 存储**：认证报告、估值报告、购买凭证等上传到 IPFS
2. **哈希上链**：文件哈希写入智能合约，确保不可篡改
3. **时间戳证明**：区块链时间戳证明文件存在时间

### 3.3 工作流程

```
1. 用户提交资产
   ↓
2. 平台初审（基本信息、图片、凭证）
   ↓
3. 发送至鉴定机构（至少 2 家）
   ↓
4. 鉴定机构返回报告
   ↓
5. 平台验证报告真实性（签名、证书）
   ↓
6. 上传报告到 IPFS，哈希上链
   ↓
7. 估值机构进行估值（至少 2 家）
   ↓
8. 托管机构接收实物资产
   ↓
9. 购买保险，保险信息上链
   ↓
10. 所有验证通过后，资产状态改为 "verified"
   ↓
11. 允许代币化并上线
```

## 4. 前端展示

在资产详情页展示：
- **认证状态徽章**：已验证/待验证/已拒绝
- **鉴定机构信息**：显示参与鉴定的机构名称和认证日期
- **认证报告**：可下载或在线查看（脱敏处理）
- **估值信息**：显示最新估值和估值机构
- **托管信息**：托管机构名称（模糊位置）
- **保险信息**：保险公司和保额

## 5. 合规要求

- **透明度**：所有认证信息对投资者可见
- **可追溯**：认证历史完整记录
- **不可篡改**：关键信息链上存证
- **定期复检**：高价值资产定期重新认证
